# Chapter Video System — Production Bible

## Purpose
Each reading unit gets a short cinematic trailer, not a summary.
The video should create curiosity, establish the emotional temperature of the chapter, and end with a clear reading invitation without revealing the chapter's resolution.

## Master format
- Master aspect ratio: 9:16
- Resolution: 1080 × 1920
- Frame rate: 30 fps
- Target duration: 18–22 seconds
- Export: H.264 MP4
- Safe composition must support 1:1 and 16:9 derivative crops.
- Hebrew and English use the same edit with separate text layers. Do not show both languages at once in the social master.

## Visual language
- Premium literary techno-feudal science fiction.
- Cinematic realism, restrained rather than game-like.
- Dark graphite, cold navy, ivory, steel and weathered gold.
- Faction accents only when narratively relevant.
- Architecture should feel like technology became civilization, not generic cyberpunk.
- No medieval fantasy shorthand, no crowns/thrones/castles copied from existing franchises.
- Screens and UI are used as dramatic evidence, not decoration.

## Typography
- Assistant is the primary typeface for Hebrew and English.
- Headline: 700–800.
- Secondary copy: 500–600.
- Maximum 7 words per text card.
- Prefer no more than 2 narrative text cards before the end card.
- System strings may use a restrained monospace treatment.

## Master rhythm
1. 0:00–0:02 — Hook: image, sound or system event before explanation.
2. 0:02–0:06 — Establish place / person / normal state.
3. 0:06–0:11 — Disruption.
4. 0:11–0:16 — Escalation or impossible question.
5. 0:16–0:19 — Chapter signature line / unresolved beat.
6. 0:19–0:22 — Chapter title + READ NOW.

Not every chapter needs all six beats, but the emotional curve should remain recognizable.

## Sound
Every chapter receives a signature sound bed made from 3 layers:
- environment,
- system/mechanical texture,
- musical pressure.

Use silence as an event. One half-second drop to near silence is preferable to constant trailer noise.

Avoid generic epic-trailer brass unless the chapter explicitly earns it.

## Text and spoilers
- Never explain the resolution.
- Never reveal a betrayal before the reader encounters it.
- Never use a later chapter's lore to sell an earlier chapter.
- A trailer may quote one line from the chapter if it functions as a question, threat, promise or unresolved idea.
- System messages may be shown exactly when they are essential to the scene.

## Character consistency
Canonical faces, costume language, faction insignia and architecture must use approved assets.
If a character does not yet have a canonical visual, use environment/object POV rather than inventing a face.

## End card
HE:
כס התבונה
[פרולוג / פרק N] — [שם הפרק]
קראו עכשיו

EN:
THE INTELLIGENCE THRONE
[PROLOGUE / CHAPTER N] — [TITLE]
READ NOW

Duration: 2–3 seconds.

## Website integration
Each unit should eventually support:
- videoPortrait: 9:16 MP4
- videoLandscape: optional 16:9 MP4
- posterPortrait
- posterLandscape
- captionsHe
- captionsEn
- durationSeconds
- status: concept / approved / published

Video should appear before the chapter title only as an optional teaser. It must never autoplay with sound in the reader.

## Production pipeline
For each unit:
1. Read the actual chapter.
2. Extract the chapter's emotional promise, not its plot summary.
3. Write a 20-second beat sheet.
4. Select 4–6 visual shots.
5. Validate canon and spoiler boundary.
6. Generate/produce visual assets.
7. Assemble master edit.
8. Produce HE and EN text variants.
9. Export 9:16 master.
10. Author approval.
11. Only after approval: publish asset and connect it to the chapter.
