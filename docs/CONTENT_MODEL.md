# Content model

## Publication lifecycle
`draft → review → approved → scheduled → published → archived`

## Units
- Book
- Part
- Prologue
- Chapter 01–25
- Epilogue

## Chapter requirements
Each chapter supports Hebrew and future English content, release scheduling, public-date visibility, artwork, social metadata, version history and spoiler gating.

## Versioning
Published text is never silently overwritten. Material literary changes create a new chapter version; typo-level corrections may update the current publishing version while retaining history.
