# Visual asset system

Only approved canonical assets belong in `public/assets`.

## Folders
- `brand/` — book logo, wordmark, favicon, visual-system assets
- `factions/` — Seven Powers crests and variants
- `characters/` — canonical character portraits/sheets
- `locations/` — canonical environment art
- `chapters/` — chapter artwork
- `social/` — generated campaign/social exports

## Canonical naming
Use lowercase kebab-case, English identifiers and explicit variants.

Examples:
- `characters/astra/portrait-v1.webp`
- `characters/mara-venn/portrait-v1.webp`
- `factions/aperture-dominion/crest-gold.svg`
- `chapters/chapter-01/hero-v1.webp`

## Approval
Concept art stays outside production folders until explicitly approved as canonical.
